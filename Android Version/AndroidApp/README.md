# 黄果短剧 Android 应用

原生 Android 应用。工程位于此目录，采用已选定的方案二界面；目录和封面由应用读取并缓存在本机，视频由 Media3 HLS 播放器播放。界面只使用站点的影片数据，不加载站点广告页面。

## 构建与安装

需要 Android SDK（API 37、Build Tools 36）和 JDK 17 或更高版本。在 PowerShell 中运行：

```powershell
.\gradlew.bat :app:assembleDebug
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
```

构建后，调试安装包位于 `app/build/outputs/apk/debug/app-debug.apk`，当前版本 **0.1.17**。此调试包仅供开发测试；分发和手机升级请使用正式签名包。生成的安装包不提交到源码仓库。

### 正式签名包

在 PowerShell 7 中运行 `./scripts/build-release.ps1`，输出到 `app/build/outputs/apk/release/HuangGuo-Android-v0.1.17-release.apk`。首次构建需要联网取得 Gradle 的发布版依赖；依赖齐全后可加 `-Offline`。

固定发布密钥保存在 `%USERPROFILE%\.android\huangguo-release.jks`，密码保存在 `%LOCALAPPDATA%\HuangGuoSigning\release-password.txt`，均位于项目目录之外，文件访问权限限于当前 Windows 用户和 SYSTEM。**请把密钥文件与密码分别备份到安全的位置。**后续版本必须继续使用同一把密钥；丢失密钥或密码会失去直接更新正式包的能力。

调试包与正式包签名不同，不能相互覆盖安装。日常发版和后续改动始终使用正式签名脚本。

## 应用内更新

应用启动约 3 秒后检查 [Android GitHub Releases](https://github.com/MrSsg/HuangguoAPP-for-Andriod/releases)。自动检查每 12 小时最多一次；“我的 → 设置”可手动检查，每个滚动 60 分钟内最多 5 次，超过后显示顶部轻提示。发现新版后，应用会显示版本和更新说明，用户点击“下载并安装”后下载、校验 APK，再交给 Android 系统安装。首次从应用内安装时，系统可能要求允许此应用安装未知来源的应用。版本信息读取最新 Release 的固定附件 `android-update.json`，不占用 GitHub REST API 的每小时额度。

发布更新时，在该仓库创建正式 Release（不要标记为 prerelease），Tag 使用 `v版本号`，同时上传 `scripts/build-release.ps1` 生成的 `HuangGuo-Android-v版本号-release.apk` 和 `android-update.json`。如需展示更新内容，可先填写清单中的 `notes` 字段。每次递增 `versionCode` 和 `versionName`，继续使用同一发布密钥；应用按 `versionCode` 比较，并使用清单中的 SHA-256 校验下载结果。0.1.17 尚未发布到 GitHub Releases，首次安装或从旧版升级需要手动分发正式包。

## 已接入

- 首页、成人剧场、AI 专区、全局搜索、详情、片单和本地成年确认。
- 剧场与 AI 子栏目按纵向网格展示整页作品，滑至底部自动续载后续页。
- 首页 Banner 与「精选推荐」「最近上新」读取官网首页对应区域；「更多」进入官网推荐榜或上新列表。首页与分类先展示上次的目录缓存，再后台更新；只在内容实际变化时显示“更新成功”。封面加密数据解码后缓存在本机，容量上限 150 MB。
- 首页 Banner 下方提供常用标签与「全部类型」入口；完整标签页按主题分组，点击标签直接进入作品网格，滚动到底自动接续网站后续页。搜索栏支持 `#标签名` 精确进入对应列表。
- 底栏“我的”分为观看历史和我的收藏两个切换页面，默认显示观看历史。历史按作品合并，显示最近观看集数，最多保留最近 50 部；已看完的剧集也保留记录。两页可分别清空。
- 用户可用账号和密码注册、登录，并在“设置 → 账号管理”验证旧密码后修改密码；登录后收藏及观看历史同步到 Back4App，同一账号重新安装或换设备可取回。首次登录会把原本机访客片单并入账号。云端片单按账号隔离，删除和清空会同步；离线时本机仍可使用，联网后可在“我的 → 设置 → 账号管理”手动同步。
- 首页左上角显示头像，未登录时点击进入登录；登录后点击头像进入“设置 → 账号管理”，可从相册更换头像。设置按钮与“我的”的片单搜索栏同排；片单搜索只筛选观看历史和收藏。观看历史与收藏的清空入口位于设置，确认弹窗使用应用内样式。
- 系统明暗主题、按封面取色的 Banner、每 3 秒自动循环轮播及手动滑动切换、分类页滚动收起标题栏。Banner 下一张图片在解码后才进入动画，切换中保留当前画面；手动切换后重新计时，应用退到后台时暂停。
- 原生 HLS 播放、续播、选集、上下滑动切集；AI 独立影片按当前子栏目滑到下一部。视频区域单击可播放／暂停，控件采用 Windows 版的浮动遥控岛布局。
- 竖屏与横屏拖动进度条时，小窗跟随滑块显示目标时间的真实视频画面；正片继续播放，松手后才跳转。预览使用独立静音播放器，按约 5 秒取邻近画面且限制请求频率，拖动结束、换集或应用暂停时释放。当前站点只提供单一清晰度 HLS，预览画面虽小，源片段流量仍按原视频计算。
- 手动选集与自动切集都从所选集片头开始；从详情首次进入播放器仍续播未看完的进度。播放结束记录不会在切集或退出时被覆盖，旧版误存到片尾的未完成记录也不会触发连续跳集。
- 播放控件隐藏时，屏幕底边上方 14dp 保留方案三的 3dp 纯黄色细进度线，不显示圆点或底轨；点击画面时进度线移动到原有悬浮进度条位置，控件收起时反向过渡。系统关闭动画时直接切换状态。
- 视频区域双击播放／暂停，单击显示或隐藏控件；控制栏可选择 0.5、0.75、1、1.25、2、3 倍速。播放时长按临时 2 倍速，长按后下滑锁定；再次长按下滑解锁并恢复用户手选倍速，锁定与解锁使用系统震动反馈。横滑视频区域精细调整进度，整屏宽度对应片长的 20%，松手才跳转；普通上下滑仍切集。播放器返回按钮与标题放在画面上方偏左的位置，标题栏无半透明背景。
- 从影片详情返回时恢复首页、剧场、AI、搜索、片单和更多列表的纵向位置、横向影片行、筛选与已加载作品。单击当前底栏按钮保留位置，双击回顶并刷新相应栏目，图标播放跳弹动画。
- 播放器图标已保存为 Android 矢量资源。详情返回按钮的图标与文字共用一条居中轴线。
- 当前 CDN 的加密封面解密后在第 7 个字节有一致的 `0x0E` 异或变化，影响 JPEG 与 PNG。应用通过文件头识别并修复该字节，旧的 Android 内容缓存也会在读取时校正；不再内置逐片备用封面。联网恢复或应用回到前台时，可见的失败封面会重试。
- 视频切换时保留当前画面直到下一张封面准备好；首次加载使用波浪骨架与中央加载图标。

## 当前验证

已在连接的 Android 17 手机上验证安装、真实目录、分类、封面解密、详情、HLS 播放和滑动到下一集；Banner 连续经过最后一张回到第一张时，监测到的空白帧数为 0。封面格式检查覆盖推荐、上新及分类多页的 144 张真实图片：修复前 38 张无法解码，修复后 144 张均可解码。应用内另对第 2、3 页的 141 张封面完成 WebView 解码检查，141 张均通过；首页当前显示的封面也全部加载。`python qa/verify_cover_header.py` 与 `node qa/check-cover-pages.mjs` 可复测。视频媒体文件本身不做离线缓存，收藏、观看历史和头像已验证可在测试版卸载重装后恢复。
