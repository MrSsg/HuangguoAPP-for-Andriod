# 黄果短剧 Android

黄果短剧是一款面向 Android 手机的非官方短剧客户端。它将剧集浏览、搜索、收藏与播放整合在一个界面中，提供成人剧场和 AI 专区。应用读取站点的影片目录与视频资源，并使用原生播放器播放 HLS 视频；观看前需要确认已达到所在地法定年龄。

## 应用特色

- **快速找剧**：首页展示焦点内容、精选推荐和最近上新；剧场与 AI 专区支持分类浏览、连续加载。可以按剧名搜索，也可以输入 `#标签名` 查找对应类型。
- **顺手的播放器**：支持续播、选集、上下滑动切换剧集或 AI 作品、横滑精细调整进度，以及竖屏和横屏播放。顶部和底部保留系统手势区域；普通播放时透明状态栏常显，全屏时隐藏状态栏，竖屏资源保持竖屏、横屏资源自动横屏，返回时先退出全屏。拖动进度条时可查看目标位置的画面预览。
- **灵活控制播放**：提供 0.5～3 倍速，长按可临时以 2 倍速播放；播放控件收起后仍保留细进度线。
- **保留自己的片单**：观看历史和收藏保存在本机。登录账号后，可将片单同步到云端，在重新安装或换设备后取回；离线时仍可使用本机片单。
- **减少等待**：目录与封面会缓存在设备上，打开页面时先显示已有内容，再在后台获取更新。界面跟随系统明暗主题切换。
- **应用内更新**：设置中可检查新版本；下载的安装包会经过完整性校验，再交给 Android 系统安装。

## 0.2.0 播放体验更新

当前集缓冲充足后，提前静音准备下一集的播放器、首帧与开头数据；切集时直接复用，回到上一集恢复未完成的观看进度。视频片段使用 128 MiB 本地缓存。当前集卡顿、拖动进度或退出播放页时释放待播实例，快速连切时只让最终选集起播。Android 真机回归覆盖播放器复用、续播、快速连切、缓冲与进度预览、缓存和资源释放，运行方法见 `qa/episode-playback.md`。

## 安装

公开发布的正式安装包可在 [GitHub Releases](https://github.com/MrSsg/HuangguoAPP-for-Andriod/releases) 下载，文件名格式为 `HuangGuo-Android-v版本号-release.apk`。应用需要 Android 8.0（API 26）或更高版本。

调试包与正式包使用不同签名，不能直接相互覆盖安装。应用内更新适用于使用同一签名的正式包。

## 从源码构建

需要 JDK 17 或更高版本，以及 Android SDK（API 37、Build Tools 36）。在 PowerShell 中运行：

```powershell
.\gradlew.bat :app:assembleDebug
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
```

生成的调试包位于 `app/build/outputs/apk/debug/`，不会提交到源码仓库。正式包由维护者使用 `scripts/build-release.ps1` 和项目外保存的签名密钥生成。

## 项目结构

- `app/src/main/java/`：Android 容器、原生播放、数据与更新逻辑。
- `app/src/main/assets/`：应用内页面与样式。
- `qa/`：目录、封面和界面的验证脚本。
- `scripts/`：发布构建脚本。

当前源码版本为 **0.2.0**。作品卡片和 Banner 从点击时的位置展开为全屏详情，封面使用等比例缩放与裁切，标题和评分同步过渡。详情页顶部不显示头像、搜索栏，底栏位于详情卡片下方。系统返回、页面返回按钮和详情顶部下拉会收回原卡片；下拉未达到关闭距离时回弹。列表纵向位置、横向片单位置和分类页精简栏会恢复；打开过程中返回可以直接反向收回。手势中的四角弧度使用设备报告的圆角，未报告时使用默认值。支持减少动态效果设置。

转场使用随包内置的 MIT 开源 `flip-toolkit` 7.2.6 弹簧核心和 `rematrix` 0.2.2，许可证与来源保存在 `app/src/main/assets/vendor/`。共享卡片几何、封面裁切、手势与 Android 预测返回适配位于 `card-transition.js`。`qa/check-card-transition.mjs` 使用独立 Chrome 预览和模拟数据检查转场、恢复位置、返回中断及重试，不访问用户账号。

本项目是非官方客户端，不隶属于内容站点；影片目录和播放可用性取决于站点服务。
